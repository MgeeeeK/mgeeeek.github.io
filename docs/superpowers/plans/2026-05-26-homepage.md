# Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Abhi's portfolio homepage as a pixel-faithful, fully responsive Next.js page with sticky nav (Work dropdown), Hero, Work grid, and Contact/About sections.

**Architecture:** Hybrid layout — Flex/Grid for content structure, `position: absolute` for decoratives only. One component per section, each self-contained with its own CSS Module. Shared project data in `lib/projects.ts`.

**Tech Stack:** Next.js 14 (App Router, TypeScript), Tailwind CSS (tokens), CSS Modules (scoping), Vitest + React Testing Library, self-hosted Helvetica, Playfair Display via `next/font/google`, Playwright MCP for visual verification against Figma.

- [ ] **Step 4: Create `components/Nav/Nav.tsx`**

```tsx
'use client'

import { useState, useEffect, useRef } from 'react'
import Link from 'next/link'
import { PROJECTS } from '@/lib/projects'
import styles from './Nav.module.css'

export default function Nav() {
  const [isOpen, setIsOpen] = useState(false)
  const navRef = useRef<HTMLElement>(null)

  useEffect(() => {
    function handleClickOutside(e: MouseEvent) {
      if (navRef.current && !navRef.current.contains(e.target as Node)) {
        setIsOpen(false)
      }
    }
    function handleEscape(e: KeyboardEvent) {
      if (e.key === 'Escape') setIsOpen(false)
    }
    document.addEventListener('mousedown', handleClickOutside)
    document.addEventListener('keydown', handleEscape)
    return () => {
      document.removeEventListener('mousedown', handleClickOutside)
      document.removeEventListener('keydown', handleEscape)
    }
  }, [])

  function scrollToContact() {
    document.getElementById('contact')?.scrollIntoView({ behavior: 'smooth' })
    setIsOpen(false)
  }

  return (
    <nav className={styles.nav} ref={navRef}>
      <div className={`${styles.links} ${isOpen ? styles.linksOpen : ''}`}>
        <button
          className={styles.workBtn}
          onClick={() => setIsOpen((prev) => !prev)}
          aria-expanded={isOpen}
          aria-haspopup="listbox"
        >
          Work
        </button>
        <button className={styles.contactBtn} onClick={scrollToContact}>
          Contact &amp; About
        </button>
      </div>

      {isOpen && (
        <div className={styles.dropdown}>
          <ul className={styles.dropdownList} role="list">
            {PROJECTS.map((project) => (
              <li key={project.slug} className={styles.dropdownItem}>
                <Link href={project.href} onClick={() => setIsOpen(false)}>
                  {project.label}
                </Link>
              </li>
            ))}
          </ul>
        </div>
      )}
    </nav>
  )
}
```

- [ ] **Step 2: Implement wide-screen centering (critical architectural step)**

The design is 1280px wide. At wider viewports (1080p, 1440p, 4K), section backgrounds must stay full-width while content + decoratives stay centered at 1280px. This requires every section to have a full-width outer shell and a max-width inner wrapper. **Decoratives must live inside the inner wrapper** — if they're in the full-width shell, they'll drift off-center on wide screens.

**Pattern to apply to every section's TSX:**
```tsx
// WRONG: decoratives in the full-width section
<section className={styles.section}>          {/* full-width bg */}
  <div aria-hidden className={styles.decoratives}>  {/* ← wrong, bleeds wide */}
  <div className={styles.content}>

// CORRECT: everything inside the centered inner wrapper
<section className={styles.section}>          {/* full-width bg */}
  <div className={styles.inner}>              {/* max-width: 1280px, margin: auto, position: relative */}
    <div aria-hidden className={styles.decoratives}>  {/* ← correct, scoped to 1280px */}
    <div className={styles.content}>
```

**Apply the `.inner` wrapper pattern to all four CSS modules:**

`Nav.module.css` — add:

.inner {
  max-width: 1280px;
  margin: 0 auto;
  height: 100%;

}
